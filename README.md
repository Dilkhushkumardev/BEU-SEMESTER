It delivers 10-section conceptual deep-dives, live rendered KaTeX equations, 45 full lab manuals with viva answers, an AI visual explainer, and zero-latency global search.

## 🚀 Getting Started

### 📋 Prerequisites
Ensure you have **Node.js 18+** and **npm** installed on your machine:
```bash
node -v
npm -v
```

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Dilkhushkumardev/BEU-SEMESTER.git
cd BEU-SEMESTER
```

### 2️⃣ Install Dependencies
```bash
npm install
```

### 3️⃣ Start Development Server
```bash
npm run dev
```
Open **`http://localhost:5173/`** in your browser.

### 4️⃣ Quality Gates & Validation
```bash
# Static type checking
npm run typecheck

# Fast linter analysis
npm run lint

# Production build
npm run build
```
